# SELO Demo Page

Static GitHub Pages site for the SELO project.

## Files

- `index.html`: main project page
- `page1.html`: problem and setup
- `page2.html`: method and quantitative diagnostics
- `page3.html`: qualitative results and role
- `assets/`: centered project figures used by the website
- `docs/SELO_Portfolio_first3pages.pdf`: portfolio PDF with the final MIST page removed and the updated mIoU chart

## Deploy

Upload the contents of this folder to a GitHub Pages repository such as `username.github.io`, or place them in the root of an existing repository and enable GitHub Pages from the repository settings.
